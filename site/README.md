# Feedback Observatory — static GitHub Pages site

**Public URL after Pages is enabled:** https://ifrvn.github.io/ai-semiconductor-feedback/

This site is built with HTML, CSS and vanilla JavaScript. Historical time-series, temporal-validation metrics and deterministic **hypothetical** scenario outputs are generated at deploy time from data and model code already committed in the repository. No API key, paid hosting or external backend is required. Fonts use optional Google Fonts; system-font fallback is included.

## Local preview

From repository root:

```sh
PYTHONPATH=. python site/build_data.py
python -m http.server 8000 --directory site
```

Open http://localhost:8000 . Running `index.html` directly as a `file://` page may block the dataset fetch.

## Deployment

1. Repository Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Actions → **Deploy research dashboard to GitHub Pages** → Run workflow, or push to `main`.
3. After the deployment succeeds, open https://ifrvn.github.io/ai-semiconductor-feedback/.

Workflow: `.github/workflows/pages.yml`. It builds `site/data.json` using `PYTHONPATH=. python site/build_data.py`, verifies its schema and publishes the `site/` directory through the official GitHub Pages actions. If repository Pages has never been enabled, an administrator may need to configure the source setting first.

## Honesty of evidence

- Epoch data: grouped, rounded, purchase-weighted theoretical performance/dollar. **Not observed AI training workload efficiency**.
- SIA data: nominal sector revenue. **Not manufacturing capacity**.
- Sector and performance feedback scenarios: uncalibrated synthetic assumptions, **not forecasts**.
- The 5–95 percentile bands from parameter sampling are **not confidence intervals or posterior probabilities**.

All datasets are generated by local Python without reaching out to external data services, ensuring a reproducible static deployment.

## Internationalization

The dashboard supports **Simplified Chinese (`zh-CN`) and English (`en`)** via `site/i18n.js`, without a build tool or translation service. Use the language switch in the header. The choice persists in `localStorage` under `feedback-language`; first visit follows the browser language. The document `lang` attribute and accessibility labels are updated on language changes. Dynamic chart and scenario labels are translated as they are rendered.

To maintain translations, add a source-string/English-string entry to the `translations` dictionary in `site/i18n.js`. The original Chinese text is the fallback and source of truth. Check new UI strings in both languages and both color themes before publishing.

## Sector investment and capacity mechanism (exploratory)

The four-sector simulation separates **internal investment** (`investment_fraction × B`) from **ring-fenced external project financing** (`expansion_project_financing`, default 0.75 normalized investment units/year). External project financing pays for expansion directly and is **not added to B**, avoiding double counting. The pre-existing `external_funding` is a separate flow into B.

Each period, investment is allocated across wafer, HBM, packaging and power using baseline investment weights multiplied by a bounded demand-to-capacity gap signal. Projects add capacity only after the sector-specific construction delay; existing capacity still depreciates. The model starts with no committed construction pipeline before 2026, so an initial supply dip can persist even with higher investment.

**Important:** 0.75 and the responsiveness parameters are illustrative assumptions, not estimates of actual industry financing. The model does not infer physical chip shipment volumes. These choices should be stress-tested and replaced with empirically supported financing and build-out data before forecasting. The uncertainty sampler now varies both external project financing and gap responsiveness. Neither the baseline nor sensitivity ranges should be interpreted as a forecast.
