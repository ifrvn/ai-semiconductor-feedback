# Feedback Observatory — static GitHub Pages site

**Public URL after Pages is enabled:** https://ifrvn.github.io/ai-semiconductor-feedback/

This site is built with HTML, CSS and vanilla JavaScript. Historical time-series, temporal-validation metrics and deterministic **hypothetical** scenario outputs are generated at deploy time from data and model code already committed in the repository. No API key, paid hosting or external backend is required. Fonts use optional Google Fonts; system-font fallback is included.

## Local preview

From repository root:

```sh
PYTHONPATH=. python site/build_data.py
python -m http.server 8000 --directory site
```

Open http://localhost:8000 . Running `index.html` directly as a `file://` page may block the dataset fetch.

## Deployment

1. Repository Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Actions → **Deploy research dashboard to GitHub Pages** → Run workflow, or push to `main`.
3. After the deployment succeeds, open https://ifrvn.github.io/ai-semiconductor-feedback/.

Workflow: `.github/workflows/pages.yml`. It builds `site/data.json` using `PYTHONPATH=. python site/build_data.py`, verifies its schema and publishes the `site/` directory through the official GitHub Pages actions. If repository Pages has never been enabled, an administrator may need to configure the source setting first.

## Honesty of evidence

- Epoch data: grouped, rounded, purchase-weighted theoretical performance/dollar. **Not observed AI training workload efficiency**.
- SIA data: nominal sector revenue. **Not manufacturing capacity**.
- Sector and performance feedback scenarios: uncalibrated synthetic assumptions, **not forecasts**.
- The 5–95 percentile bands from parameter sampling are **not confidence intervals or posterior probabilities**.

All datasets are generated by local Python without reaching out to external data services, ensuring a reproducible static deployment.
